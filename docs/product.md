# Cards — описание продукта

> Статусы: **Согласовано** — обсудили и приняли; **Предложено** — вариант ассистента, ждёт подтверждения.

## Суть

Мобильное веб-приложение (PWA) для быстрого повторения пачек карточек «слово ↔ перевод».
Тап переворачивает карточку, свайп — оценка «помню / не помню». ИИ собирает пачку по заданной теме.

Идея выросла из бумажных карточек на курсах английского: на одной стороне слово, на другой — перевод.

## Для кого

- Сейчас: автор — освежить английский без систематической учёбы.
- Позже: проверить пользу для других людей. Монетизация — возможная перспектива, спрос не проверен.

## Принципы

- Простота интерфейса важнее количества функций.
- Каждый этап доводим до работающего результата на телефоне.
- Адаптивные интервалы (Anki/FSRS) — существующая технология, не наша уникальность.
- Самооценку по пачке не выдаём за точный размер словарного запаса.

## Механика повторения (Согласовано)

- Тап — перевернуть карточку.
- Свайп вправо — «помню», влево — «не помню». Дублирующие кнопки внизу экрана.
- Можно свайпнуть, не переворачивая, если уверенно помню.
- «Не помню» — карточка уходит в конец текущей стопки; «помню» — уходит из текущего прохода.
- Направление прохода: EN → RU или RU → EN.
- После прохода — итоги этой пачки.

## Первая законченная проба (MVP)

Сценарий: выбрать тему → получить пачку → пройти её на телефоне → увидеть итоги → позже вернуться к сохранённым карточкам.

Входит:
- Пара языков английский / русский, 20–30 карточек по теме.
- Генерация пачки: сначала мок-генератор за общим интерфейсом, затем реальный ИИ (Согласовано).
- Понятная обработка ошибок генерации, исправление неудачной карточки.
- Хранение только на устройстве, без аккаунтов (Согласовано).
- «Прогресс» в MVP (Согласовано):
  1. прерванный проход продолжается с места;
  2. у пачки сохраняются итоги прошлых проходов;
  3. пишется лог каждого ответа (пока не показывается — задел для интервалов и срезов).

Не входит: интервальные повторения, напоминания, статистика, другие языки, озвучка, аккаунты/синхронизация, адаптация под планшет/desktop. См. [ideas.md](ideas.md).

## Критерий успеха первой пробы

Автор неделю пользуется приложением с домашнего экрана iPhone для повторения 2–3 сгенерированных пачек и может сказать, что в нём мешает и чего не хватает.
