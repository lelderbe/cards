## 0. Каркас — ✅

Документы в `docs/`, OpenSpec, проект Vite + React + TS, PWA-плагин с манифестом.

**Проверка:** `npm run dev -- --host` открывается на iPhone в локальной сети ✅; `npm run build` проходит ✅.

## 1. Проход по встроенной пачке — ✅ · change `add-study-session`

Встроенная пачка (~25 слов). Переворот тапом, свайпы и кнопки, очередь «не помню → в конец», выбор направления EN → RU / RU → EN, экран итогов. Без сохранения.

**Проверка:** на iPhone прохожу пачку до итогов ✅; тесты логики очереди и итогов зелёные ✅.

## 2. Сохранение пачек и прохода — ✅ · change `add-local-persistence`

IndexedDB, список пачек (встроенная пачка попадает в БД при первом запуске), продолжение прерванного прохода (до конца следующего дня после последнего ответа, см. D-15).

**Проверка:** закрыл приложение посреди прохода → открыл → продолжаю с той же карточки ✅; протухший проход убирается при запуске ✅; тесты хранилища и срока зелёные ✅.

## 3. Лог ответов — ⬜ · change `add-answer-log`

Запись каждого ответа в лог (без отображения) — данные для будущих интервальных повторений. Итоги прошлых проходов не показываем (D-06, D-16).

**Проверка:** после прохода в DevTools видна запись на каждый ответ, включая повторные «не помню»; тесты записи лога зелёные.

## 4. Деплой и установка на iPhone — ⬜

Хостинг с HTTPS, иконки, офлайн-кеш.

**Проверка:** иконка на домашнем экране; пачка проходится в авиарежиме.

## 5. Создание пачки с мок-генератором — ⬜ · change `add-deck-creation`

Экран «тема → черновик → правка → сохранить», редактор сохранённой пачки, состояния загрузки и ошибок. Генератор за интерфейсом; мок имитирует задержку и ошибки.

**Проверка:** создаю пачку по теме, исправляю карточку, сохраняю, прохожу; при имитации ошибки вижу понятное сообщение и «Повторить».
