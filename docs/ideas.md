# Будущие возможности

Не входят в первую пробу. Порядок не означает приоритет — выбираем после обкатки.

## Из исходного видения (автор)

- **Адаптивные интервалы повторений** по результатам пользователя (готовые алгоритмы: FSRS, SM-2 — не изобретаем своё). Данные для них копим с этапа 3 (лог ответов).
  - Видение автора: приложение само даёт карточки для повтора и сообщает, когда пора. Схему (лесенка интервалов или FSRS) уточним, когда дойдём до этапа.
  - Повторять поверх пачек: одна виртуальная пачка «К повторению» с карточками всех пачек, которым подошёл срок (карточка одна на все пачки — D-17). Отдельных пачек «через час / через день» не делаем: важно, что пора сейчас; будущее — подсказка «следующие 12 — завтра». Расписание, вероятно, отдельно по направлениям (узнать слово и вспомнить его — разные навыки); лог направление уже пишет.
- **Напоминания о повторении.** Заниматься можно в любое время; внеплановый повтор пересчитывает следующий срок. На iOS — Web Push для установленной PWA.
- **Срезы прогресса:** улучшение и забывание. Методика не выбрана. Самооценку по пачке не выдаём за точный размер словарного запаса.
- **Другие языки**, выражения и термины, не только отдельные слова.
- **Озвучка** видимой стороны, возможно обеих (Web Speech API как первый вариант).
- **Планшет и desktop** — адаптивная вёрстка, клавиатурное управление.
- **Проверка пользы для других людей**, затем — возможная монетизация.

## Предложения ассистента

- Отмена последнего свайпа (защита от случайного жеста).
- Экспорт / импорт пачек в JSON — резервная копия и перенос между устройствами без аккаунтов.
- Синхронизация между устройствами (аккаунт + облачная БД).
- Перегенерация одной неудачной карточки через ИИ.
- Пачка «Без пачки» вместе с перемещением / добавлением существующих карточек в другую пачку: разбирать карточки, оставшиеся без пачки после удаления пачки или «убрать из пачки».
- Показ в черновике, что карточка уже есть в другой пачке («уже в „Путешествиях“»).
- Пример употребления слова на обратной стороне.
- Проход только по «трудным» карточкам пачки.
- Шаринг пачки ссылкой.
