# Spec Delta

## Purpose

Хранение пачек карточек на устройстве пользователя: первичное заполнение встроенной пачкой, список сохранённых пачек и экран отдельной пачки, с которого начинается или продолжается проход.

## ADDED Requirements

### Requirement: Хранение пачек на устройстве
Система SHALL хранить пачки (название, языки сторон, карточки) только на устройстве пользователя, без сервера и аккаунта. Сохранённые пачки MUST оставаться доступными после закрытия и повторного открытия приложения.

#### Scenario: Пачка переживает перезапуск
- **WHEN** пользователь закрывает приложение и открывает его снова
- **THEN** список пачек показывает те же пачки с тем же числом карточек

#### Scenario: Работа без сети
- **WHEN** пользователь открывает приложение без подключения к сети
- **THEN** сохранённые пачки загружаются так же, как с сетью

### Requirement: Первичное заполнение встроенной пачкой
При первом запуске на устройстве система SHALL записать в хранилище встроенную пачку из 20–30 карточек на одну тему; у каждой карточки есть английское слово и русский перевод. Первичное заполнение MUST выполняться один раз: повторные запуски не создают дубликат пачки.

#### Scenario: Первый запуск
- **WHEN** пользователь впервые открывает приложение на устройстве
- **THEN** список пачек содержит встроенную пачку с её названием и числом карточек

#### Scenario: Повторный запуск
- **WHEN** пользователь открывает приложение второй и последующие разы
- **THEN** встроенная пачка присутствует в списке ровно один раз

### Requirement: Список пачек
Система SHALL открываться на списке пачек. Для каждой пачки список SHALL показывать название и число карточек, а для пачки с незавершённым проходом — отметку с числом ещё не вспомненных карточек. Тап по пачке SHALL открывать экран этой пачки.

#### Scenario: Пачка без незавершённого прохода
- **WHEN** у пачки нет незавершённого прохода
- **THEN** в списке видны её название и число карточек, отметки о проходе нет

#### Scenario: Пачка с незавершённым проходом
- **WHEN** у пачки есть незавершённый проход, в котором осталось 12 карточек
- **THEN** в списке у пачки видна отметка «осталось 12»

#### Scenario: Открытие пачки
- **WHEN** пользователь тапает по пачке в списке
- **THEN** открывается экран этой пачки

### Requirement: Экран пачки
Экран пачки SHALL показывать название пачки, число карточек, выбор направления прохода и кнопку возврата к списку пачек. Если у пачки нет незавершённого прохода, экран SHALL предлагать «Начать». Если есть — главную кнопку «Продолжить» с направлением прохода и числом оставшихся карточек и второстепенную кнопку «Начать заново». Выбор направления на экране относится только к новому проходу; при незавершённом проходе по умолчанию выбрано его направление.

#### Scenario: Нет незавершённого прохода
- **WHEN** пользователь открывает экран пачки без незавершённого прохода
- **THEN** видна кнопка «Начать», кнопок «Продолжить» и «Начать заново» нет

#### Scenario: Есть незавершённый проход
- **WHEN** пользователь открывает экран пачки с незавершённым проходом EN → RU, в котором осталось 12 карточек
- **THEN** видны главная кнопка «Продолжить» с подписью «EN → RU · осталось 12» и второстепенная «Начать заново»

#### Scenario: Направление по умолчанию при незавершённом проходе
- **WHEN** пользователь открывает экран пачки с незавершённым проходом RU → EN
- **THEN** в выборе направления выбрано RU → EN

#### Scenario: Возврат к списку
- **WHEN** пользователь нажимает «← Пачки» на экране пачки
- **THEN** открывается список пачек

### Requirement: Загрузка и недоступное хранилище
Пока пачки читаются из хранилища, система SHALL показывать состояние загрузки. Если хранилище недоступно или чтение завершилось ошибкой, система SHALL показать понятное сообщение об ошибке вместо пустого списка.

#### Scenario: Хранилище недоступно
- **WHEN** браузер не даёт открыть хранилище
- **THEN** пользователь видит сообщение, что сохранённые пачки не удалось загрузить, а не пустой список
