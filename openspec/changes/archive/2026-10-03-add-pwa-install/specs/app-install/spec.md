# Spec Delta

## Purpose

Приложение как установленное на телефоне: открывается по постоянному HTTPS-адресу, ставится на домашний экран iPhone со своей иконкой и названием, запускается без сети и обновляется до новой версии без потери данных пользователя.

## ADDED Requirements

### Requirement: Доступ по HTTPS
Приложение SHALL быть доступно по постоянному публичному адресу только по HTTPS. Запрос по HTTP MUST перенаправляться на HTTPS.

#### Scenario: Открытие в Safari
- **WHEN** пользователь открывает адрес приложения в Safari на iPhone
- **THEN** загружается список пачек, адресная строка показывает защищённое соединение

#### Scenario: Открытие по HTTP
- **WHEN** пользователь открывает адрес приложения со схемой `http://`
- **THEN** браузер перенаправляется на тот же адрес по `https://`

### Requirement: Установка на домашний экран
Приложение SHALL устанавливаться на домашний экран iPhone через Safari → «Поделиться» → «На экран Домой». Установленное приложение SHALL иметь название «Cards» и собственную иконку (стопка карточек), а не снимок страницы или чужой логотип. Запуск с иконки SHALL открывать приложение в полноэкранном режиме без адресной строки и панелей Safari, в портретной ориентации.

#### Scenario: Иконка на домашнем экране
- **WHEN** пользователь добавляет приложение на экран «Домой»
- **THEN** на домашнем экране появляется иконка «стопка карточек» с подписью «Cards»

#### Scenario: Запуск с иконки
- **WHEN** пользователь запускает приложение с иконки на домашнем экране
- **THEN** приложение открывается на весь экран без интерфейса Safari и показывает список пачек

#### Scenario: Вкладка браузера
- **WHEN** пользователь открывает приложение во вкладке браузера на компьютере
- **THEN** вкладка показывает иконку «стопка карточек»

### Requirement: Оформление под тему устройства
Статус-бар и фон при запуске установленного приложения SHALL соответствовать теме устройства: светлые при светлой теме, тёмные при тёмной. Содержимое приложения MUST NOT заходить под статус-бар и вырез экрана так, чтобы перекрывались элементы управления.

#### Scenario: Тёмная тема
- **WHEN** на iPhone включена тёмная тема и пользователь запускает приложение с иконки
- **THEN** статус-бар и фон тёмные, без белой вспышки и белой полосы сверху

#### Scenario: Светлая тема
- **WHEN** на iPhone включена светлая тема и пользователь запускает приложение с иконки
- **THEN** статус-бар и фон светлые, текст статус-бара читается

### Requirement: Запуск без сети
После первого успешного открытия по HTTPS приложение SHALL запускаться и работать полностью без сети: интерфейс, встроенная пачка, иконки и сохранённые на устройстве пачки, проходы и лог. Приложение MUST NOT загружать во время работы ресурсы с других адресов.

#### Scenario: Проход в авиарежиме
- **WHEN** пользователь хотя бы раз открыл установленное приложение с сетью, затем включил авиарежим и запустил его с иконки
- **THEN** список пачек загружается, и пачку можно пройти до экрана итогов

#### Scenario: Ответы без сети сохраняются
- **WHEN** пользователь проходит пачку в авиарежиме, закрывает приложение и открывает его снова уже с сетью
- **THEN** незавершённый проход продолжается с той же карточки, а ответы, данные без сети, есть в логе

### Requirement: Обновление до новой версии
После публикации новой версии установленное приложение SHALL перейти на неё само, без действий пользователя и без переустановки, не позднее второго запуска с сетью после публикации. Обновление MUST сохранять пачки, незавершённый проход и лог ответов. Пока новая версия недоступна (нет сети), приложение SHALL работать на установленной версии.

#### Scenario: Вышла новая версия
- **WHEN** опубликована новая версия и пользователь запускает установленное приложение с сетью
- **THEN** не позднее следующего запуска открывается новая версия, а пачки, незавершённый проход и лог на месте

#### Scenario: Обновление посреди прохода
- **WHEN** новая версия применяется, пока у пользователя открыт проход
- **THEN** все уже данные ответы сохранены, и проход можно продолжить с той же карточки
