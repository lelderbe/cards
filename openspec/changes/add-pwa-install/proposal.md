# Proposal

## Why

Сейчас приложение открывается на iPhone только с Mac по HTTP в локальной сети: без Mac рядом им не пользоваться, на домашний экран его толком не поставить (iOS требует HTTPS, иконки нет — вместо неё логотип Vite), а без сети оно не откроется. Чтобы этап 7 «Обкатка» был возможен, приложение должно жить на телефоне как обычное: иконка на домашнем экране, запуск в любой момент, в том числе в метро и в самолёте. Этап 4 из [docs/plan.md](../../../docs/plan.md); хостинг — D-11 в [docs/decisions.md](../../../docs/decisions.md), подтверждается этим изменением.

## What Changes

- Приложение публикуется на Vercel по HTTPS: продакшн собирается из `master`, превью-сборки — из `develop`. Проект в Vercel подключает автор вручную; в репозитории — только конфигурация.
- Своя иконка «стопка карточек» вместо логотипа Vite: favicon, иконка на домашнем экране iPhone (`apple-touch-icon`) и иконки манифеста, включая maskable для Android.
- После первого открытия по HTTPS приложение целиком (оболочка, встроенная пачка, иконки) запускается без сети: пачку можно пройти в авиарежиме.
- Новая версия после деплоя подхватывается сама при следующем запуске; пачки, незавершённый проход и лог ответов сохраняются.
- Статус-бар и фон запуска в установленном приложении соответствуют светлой / тёмной теме.

## Capabilities

### New Capabilities
- `app-install`: доступность по HTTPS, установка на домашний экран (название, иконка, полноэкранный режим), запуск без сети и обновление до новой версии без потери данных.

## Non-goals

- Серверная функция `/api/generate` и переменные окружения — этап 6.
- Свой домен: достаточно адреса `*.vercel.app`.
- Подсказка «Установите на домашний экран» и кнопка «Обновить» в интерфейсе — обновление применяется молча.
- Push-уведомления и напоминания — см. [docs/ideas.md](../../../docs/ideas.md).
- Экраны-заставки запуска (`apple-touch-startup-image`) под каждый размер iPhone: хватает цвета фона.
- CI (GitHub Actions) с проверками до деплоя — Vercel только собирает `npm run build`.
- Перенос данных между Safari и иконкой на домашнем экране — на iOS это разные хранилища (D-01), данные из dev-режима по HTTP на прод не переносятся.

## Impact

- `public/`: новая иконка `icon.svg` и PNG-иконки; `favicon.svg` Vite удаляется.
- `index.html`: `apple-touch-icon`, `apple-mobile-web-app-status-bar-style`, `theme-color` для светлой и тёмной темы.
- `vite.config.ts`: иконки в манифесте, цвета манифеста под тему, precache иконок.
- `vercel.json`: настройки сборки и заголовки кеширования (`sw.js` и `index.html` не кешируются, `assets/` — надолго).
- Новых зависимостей нет: PNG генерируются один раз через `npx @vite-pwa/assets-generator` и коммитятся.
- `docs/decisions.md`: D-11 → «Согласовано»; `README.md`: адрес приложения и как устроен деплой.
